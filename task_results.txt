- `isAuthenticated`: Validates session token from Authorization header
- `isAdmin`: Verifies user has admin privileges

**Endpoints:**
- `POST /api/login`: Authenticates users and creates sessions
- `POST /api/logout`: Terminates user sessions
- `GET /api/session`: Retrieves current session information
- `POST /api/admin/message`: Admin-only endpoint to update the greeting message
- `GET /api/admin/users`: Admin-only endpoint to list all users

**Session Management:**
- In-memory session storage using Map
- Session IDs generated with timestamp and random string
- Bearer token authentication
